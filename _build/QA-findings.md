### 要修正：資料解釈6問（suri-090〜095）が資料解釈になっていない → 実装担当へ差し戻し済み

すべて2列（項目名＋数値1列）×4行の表で、設問も「差はいくつか」「何倍か」「2番目に多いのはどれか」。
表から1〜2セルを読むだけで、単なる四則計算に堕している。suri-092 は表を眺めるだけで解ける。

SCOAの資料解釈は複数列の突き合わせが本質。構成比と実数の換算／複数系列の増加率比較／
指数と実数の混在／合計を自分で出させる／「確実にいえるもの」の判断、といった観点へ作り直しを依頼。
表は3〜4列×4〜5行まで（スマホ縦画面で横スクロールなし）、30秒で解ける計算量を条件とした。

### 要修正1：eig-082 は正解が2つある（実害あり）

```
A: Excuse me, is this seat taken?
B: ( )
選択肢: 0 I'm afraid so. / 1 Yes, please. / 2 Not at all, thanks. / 3 No, go ahead.
正解として設定: 3
```

`I'm afraid so.`（＝はい、埋まっています）も、この問いへの応答として完全に自然。
「席は空いているか」ではなく「この席は取られているか」という問いなので、肯定・否定どちらの応答もあり得る。
設問文が「最も自然なもの」であるため、受験者が0を選んでも論理的に正しく、学習の妨げになる。

**修正案**：選択肢0 を、応答として不自然なもの（例 `It's very kind of you.`）に差し替える。

### 要修正2：eig-094 の下線部の示し方が不統一（軽微）

```
c【h】air / c【h】eese / c【h】oose / c【h】ristmas
```
他の発音問題は二重字全体を囲っている（`fo【o】d` は例外的に1字、`br【ea】d` は2字）。
この問題は `ch` の発音を問うているので `【ch】air` のように綴り全体を囲うべき。
解説も「Christmasの【h】を含むchは」という不自然な言い回しになっている。

**修正案**：`【ch】air` `【ch】eese` `【ch】oose` `【Ch】ristmas` に統一し、解説を「Christmasのchは/k/、他は/tʃ/」に直す。

### 参考：maxSameARun = 1

正解位置が完全に交互になっており、シャッフルを切ると規則性が見える。
アプリ側の選択肢シャッフルが既定ONであれば実害なし。設定でOFFにできる仕様なので、
OFF時のみ出題順をシャッフルすることで回避する（アプリ側で対応）。
