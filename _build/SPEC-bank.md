# SCOA問題バンク 作成仕様（実装エージェント共通）

柏原市役所 職員採用試験 第2次「基礎能力検査（SCOA総合適性検査・テストセンター方式）」対策アプリ用の問題バンクを作成する。
受験者は **土木職B（社会人経験者・有資格者、30代想定）**。専門試験は課されないため、中学〜高校初級レベルを **速く正確に処理する** 訓練が目的。

本番仕様：**120問／60分＝1問あたり30秒**。尺度別配分は 言語20・数理25・論理25・英語30・常識20。

---

## 1. 出力形式（厳守）

担当分野ごとに **1ファイル** を書く。ファイル形式は素のJavaScriptで、末尾に何も出力しない。

```js
window.BANK_<KEY> = [
  { id:"...", cat:"...", sub:"...", q:"...", o:["","","",""], a:0, e:"...", t:"...", k:"・…\n・…", lv:2 },
  ...
];
```

### フィールド定義

| キー | 必須 | 型 | 内容 |
|---|---|---|---|
| `id` | ✔ | string | `<prefix>-<3桁連番>` 例 `suri-001`。**割り当て範囲を厳守**（重複厳禁） |
| `cat` | ✔ | string | 尺度名。`言語` `数理` `論理` `常識` `英語` のいずれか1つ |
| `sub` | ✔ | string | 小分野名。下の「担当範囲」で指定された表記を**一字一句そのまま**使う（苦手分野判定のキーになる） |
| `q` | ✔ | string | 設問文。40字以内を目安。スマホ1画面に収める |
| `s` |  | string | 補助表示（数式・英文・データ列など）。等幅フォントで別枠表示される。設問が「下線部」を指す場合は該当箇所を `【 】` で囲む（描画時に下線になる。`o` でも使える） |
| `tbl` |  | object | 資料解釈用の表。`{head:["年","A社","B社"], rows:[["2020","120","80"],...]}` |
| `o` | ✔ | string[] | 選択肢。**必ず4つ**。1つ20字以内を目安 |
| `a` | ✔ | number | 正解のインデックス（0〜3） |
| `e` | ✔ | string | 解説。**必ず根拠か計算過程を示す**。1〜3文、120字以内 |
| `x` | ✔ | string[] | **選択肢ごとの解説**。`o` と同じ順で必ず4つ。正解には「正しい理由」、誤答には「なぜ違うか／どこで間違えるか」を1文（15〜50字、70字以内）。回答の正誤にかかわらず表示される（学習者要望、2026年9月） |
| `t` |  | string | 解法のコツ・引っかけ注意。1文、60字以内。3問に1問程度で付ける |
| `k` | ✔ | string | **関連知識**。その問題の周辺論点（依拠する一般則・公式／関連語・対になる概念／典型的なひっかけ／派生論点）。「・」で始まる2〜4項目を `\n` で区切る。80〜220字。`e` `t` の言い直しは禁止。である調・体言止め。2026年8月時点で確実な内容のみ |
| `lv` | ✔ | number | 難易度 `1`（易・確実に取る）`2`（標準）`3`（やや難） |

### 品質ルール（レビューで機械チェックされる）

1. **選択肢は必ず4つ**、重複なし、空文字なし。
2. **正解位置 `a` は 0/1/2/3 に均等分散**させる。各20〜30%の範囲に収めること。連続3問以上同じ`a`にしない。
3. 「上記のいずれでもない」「すべて正しい」のような逃げ選択肢は**使わない**。
4. 誤答選択肢は**もっともらしく**作る。典型的な計算ミス・よくある誤解の結果を置く。
5. **30秒で解ける計算量**にする。筆算が3行を超える問題は作らない。本番は電卓不可。
6. **図が必要な問題を出さない。** 空間把握・展開図は文章だけで一意に決まるよう記述する。表が要る場合は `tbl` を使う。
7. 解説は「答えはA」で終わらせない。**なぜそうなるか**を書く。`k` は解説の先にある**周辺知識**を書く（学習者から「正誤だけでは知識が身につかない」という要望があり追加した。2026年9月）。
8. 数値・固有名詞・制度は**2026年8月時点で正しいもの**のみ。改正の可能性がある制度は避けるか、`t`に「改正に注意」と添える。
9. 難易度配分は **lv1:30% / lv2:50% / lv3:20%** を目安。
10. 同一論点の問題は最大3問まで（数値違いの水増し禁止。**設定や問われ方を変える**）。
11. 日本語は簡潔・平易に。受験者は隙間時間にスマホで解く。
12. JavaScriptとして構文エラーがないこと。文字列内の `"` は `\"` でエスケープ、または `'` を使う。

## 2. 既存問題の取り込み

同ディレクトリ上位の `scoa-jissen-drill.html` に既存60問がある（`const BANK = {...}`）。
**取り込み担当に指定された分野のみ**、既存問題をそのまま（`q` `o` `a` `e` `t` を変更せず）バンクの先頭に取り込み、`id` `sub` `lv` を新たに付与すること。既存問題は品質確認済みなので改変しない。取り込み担当でない分野は既存問題に触れない。

## 4. 完成チェック（自分で実行してから報告する）

`node -e "global.window={}; require('./bank/<file>.js'); const b=Object.values(window)[0];
console.log('n=',b.length);
console.log('dupIds=', b.length-new Set(b.map(x=>x.id)).size);
console.log('badOpts=', b.filter(x=>!Array.isArray(x.o)||x.o.length!==4||new Set(x.o).size!==4).length);
console.log('badA=', b.filter(x=>!(x.a>=0&&x.a<=3)).length);
console.log('noE=', b.filter(x=>!x.e).length);
console.log('aDist=', [0,1,2,3].map(i=>b.filter(x=>x.a===i).length));
console.log('subs=', [...new Set(b.map(x=>x.sub))].join(','));"`

すべて 0（`n`と`aDist`と`subs`を除く）であること、`aDist`が均等であることを確認してから完了報告する。
報告は **3行以内**：問題数／aDist／気になった点。それ以外は書かない。
