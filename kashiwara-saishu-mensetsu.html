CH.1

25分の流れと答え方

25分で答えるのは、12〜15問ほど
面接官が話す時間を除くと、自分が話せるのは15〜17分ほどが目安です。1つの答えを40〜60秒にすると、深掘りを含めて12〜15問になります。1つの答えが2分になると、聞いてもらえる質問は半分に減り、面接官が確かめたかったことが残ったまま終わります。
  1. 0〜2分入室・導入受験番号と氏名。「柏原市にお住まいなんですね」など、緊張をほぐす問いかけ
  2. 2〜5分志望動機・自己PR動画とエントリーシートの内容を、本人の口から確かめる
  3. 5〜12分職務経験の深掘りいちばん長い。「具体的には」「そのときどうしましたか」が続く
  4. 12〜16分転職理由・条件の確認なぜ今の会社を辞めるのか、年収、年下の上司、いつから働けるか
  5. 16〜21分柏原市・土木職の理解市の課題、発注者の仕事、場面を想定した質問
  6. 21〜24分人物長所と短所、ストレス、チームでの働き方
  7. 24〜25分逆質問・最後に一言

この配分は、経験者採用の個人面接でよくある流れをもとにした想定です。市は面接の進め方を公表していません。順番が入れ替わっても、聞かれる中身はこの6つの中に収まります。

型答え方の型（3種類だけ覚える）▶
共通
  • 最初の一文で結論を言う。「はい、あります」「私の強みは〜です」から始める
  • 40〜60秒で止める。足りなければ面接官が聞いてくれる。聞かれたら、それが深掘りに答える機会になる
  • 語尾まで言い切る。「〜と思うんですけど……」で終わらせない
経験を聞かれたとき（〜したことはありますか）
  • 結論 → どんな場面だったか → 自分がどう動いたか → 結果 → そこから変えたこと
考えを聞かれたとき（〜をどう思いますか）
  • 結論 → 理由 → 現場での具体例を一つ → 市の仕事でどう活かすか
場面を想定した質問（〜のとき、どうしますか）
  • まず事実を確かめる → 安全を先に確保する → 自分だけで決めず上司に報告・相談する → 相手に結果を伝え、記録を残す
困答えに詰まったときの言い方▶
  • 質問の意味が取れなかった／「恐れ入ります。〜というご質問でよろしいでしょうか」と確かめる。聞き返して構わない。ずれた答えを長く話すほうが不利
  • 考える時間がほしい／「少し考えさせてください」と言ってから、数秒おいて話す
  • 知らないことを聞かれた／「申し訳ありません、存じません。入庁までに確認します」。知っているふりをしない。現場を知っている面接官には伝わる
  • 話が長くなってしまった／「まとめますと、〜です」と自分で切る
  • 否定された・重ねて突っ込まれた／言い返さない。「ご指摘のとおり、その点は足りていないと思います。そのうえで〜」と受けてから続ける。態度が崩れないかを見ている場合がある
  • 経験がないことを聞かれた／「その経験はありません」と先に言い、近い経験と、これからどう身につけるかを話す

CH.2

書類と動画で言ったことの整理

面接官の手元には、この3つがあります
面接は、すでに提出した内容の確認から始まります。書いたこと・話したことより強く言わない、違う話をしない。この2つを守るだけで、深掘りの大半は落ち着いて答えられます。下は内容の要約です。面接前に、手元の控えの全文を声に出して読んでください。

① 自己PR

  • 強み＝仕事を最後まで責任を持って、正確にやり遂げる
  • 今の仕事＝現場の安全管理、他業者との工程調整、官公庁へ出す申請書類の作成
  • やり方＝施工マニュアルや安全基準を毎回確認。自作のチェックリストでダブルチェック（数量、図面との整合性）
  • 人との関わり＝分かりやすく伝える、必要な情報を確実に共有する
  • 結果＝大きな事故や工期の遅れを出すことなく現場を進めている。発注者や関係者から信頼をいただいている
  • 市の仕事の理解＝工事を発注し監督する立場。施工する側以上に正確さと調整が求められる
  • 柏原市＝大和川と石川が合流し、市域の約3分の2が山地。道路や下水道などの整備と維持管理で、安全な暮らしを支えたい

② 過去2年間に取り組み、成果が上がったこと

  • 何を＝新築物件に伴う給排水引込み工事、道路法第24条に基づく歩道切下げ工事の施工管理
  • 条件＝昼夜を問わず交通量の多い幹線道路など。無事故かつ工期内の竣工を目標にした
  • 難しさ＝第三者災害や渋滞のおそれ、他の埋設管、騒音・振動、建物の引き渡し日に直結する工程、限られた交通規制時間
  • 力を入れた点1＝埋設物管理者との事前協議と立ち会い。試掘で位置と深さを自分の目で確認し、防護した
  • 力を入れた点2＝近隣の住民や店舗に直接足を運び、図面や資料で説明。理解をいただいてから着工
  • 結果＝近隣との大きなトラブルや事故を出すことなく、工期内に完了
  • 学び＝行政・民間企業・地域住民など、立場の異なる関係者と意思疎通を図る調整力
  • 着地＝老朽化対策や浸水への備えで、市民の声を受け止め、関係部署や施工業者と調整し、即戦力として貢献したい

③ 録画動画面接で話したこと

  • 志望理由＝現在柏原市に住んでいる市民として、民間で培った経験を活かして、安全・安心なまちづくりに貢献したい
  • 経験＝給排水の引込み工事、歩道の切下げ工事の施工管理。埋設物管理者との事前協議と、近隣への直接の説明
  • 暮らす中で感じていること＝大雨の際の浸水対策、土砂災害への備え、インフラの老朽化対策の重要性
  • 自分の立ち位置＝施工側・申請側として現場に立ってきたので、民間側の視点や現場の苦労が分かる
  • やりたいこと＝業者の方々と同じ目線に立って寄り添った指導、市民の声を真摯に受け止める、円滑な調整
  • 締め＝柏原市民の目線を持ちながら、技術職の即戦力として
言い方に気をつける言葉（自分が使った言葉なので、必ず聞かれる前提で）
  • 「大きな事故や工期の遅れを出すことなく」「工期内に竣工させる実績を積み重ねてきました」3つの中で一番控えめな言い方に合わせる。口頭で「一度もありません」「ゼロです」とは言わない。「小さいものは？」と聞かれたら、あったことを認めて話す → 問答集 E3・E4
  • 「無事故かつ工期内での竣工を目標に」これは目標として書いた言葉。結果として「無事故でした」と言い換えない
  • 「業者の方々と同じ目線に立って寄り添った指導」（動画だけで言った言葉）発注者が業者に甘くなる、と受け取られるおそれがある。基準は緩めない、という説明を必ず添える → F3
  • 「柏原市に住んでいる市民として」（動画だけで言った言葉）最初の話題になりやすい。いつから、どこで何を感じたか、知人に頼まれたらどうするか → F1・F2・F4
  • 「即戦力として」（ES②と動画の2回）強い言葉。すぐできることと、一から学ぶことを分けて話す → 問答集 E13
  • 「発注者や関係者からも信頼をいただいています」「どんな場面でそう感じましたか」と聞かれる。実際の場面を一つ決めておく → F5
  • 「給排水引込み工事」と「道路や下水道」柏原市の水道は令和7年4月に大阪広域水道企業団へ統合された。市の仕事は下水道と道路。「上下水道」とは言わない → 問答集 E11
  • 「浸水や土砂災害への備え」大和川の本体は国の管理。市が担うのは雨水を流す下水道や水路、市道。「大和川の治水をしたい」とは言わない → 問答集 E12

C4なぜ今の会社を辞めて、市役所で働こうと思ったのですか。▶
意図

経験者の面接で、合否にいちばん響く質問です。エントリーシートにも動画にも退職の理由は出てきません。だから面接で必ず聞かれます。「また辞めないか」「本気で行政を選んだのか」の両方を見ています。

骨子
  • 今の仕事への不満から入らない。今の仕事で得たものを先に言う
  • その中で気づいたこと（例：建物が引き渡されると現場を離れる。つくった後の維持管理までは関われない）
  • だから、自分が住むまちの道路や下水道に、計画から維持管理まで長く関わりたい

必ず自分の理由で／上の例は型です。当てはまらない部分は使わないでください。本当の理由が労働時間や待遇であっても構いませんが、それだけを話さず、「その中で何を考えるようになったか」を一段はさんでください。会社や上司への不満は口にしない（問答集 Q04）。

F3「業者と同じ目線に立って寄り添った指導」とは、具体的にどういうことですか。業者に甘くなりませんか。▶
意図 動画

動画の中で、面接官がいちばん引っかかる言葉です。市の技術職は、業者の仕事を検査し、税金で代金を支払う立場です。施工側から来た人が「寄り添う」と言うと、なれ合いにならないかを必ず確かめられます。

骨子
  • 最初に「基準を緩めるという意味ではありません」と言う
  • 意味は、相手が動きやすいようにすること。協議に早く応じる、指示の理由を伝える、現場で起きそうな問題を先に確かめる
  • 施工側にいたから分かること。発注者の回答を待つあいだ現場が止まる、指示があいまいだと手戻りになる
  • 品質と安全の基準、検査は、どの業者にも同じ目で行う。一人で判断せず、記録を残す
寄り添うというのは、基準を緩めるという意味ではありません。施工する側にいたとき、発注者の方からの回答が早かったり、指示の理由を説明していただけたりすると、現場はとても動きやすくなりました。同じように、協議には早く応じ、なぜその指示なのかを伝えることを心掛けたい、という意味です。一方で、品質や安全の基準、検査は、どの業者に対しても同じ目で行います。施工側にいた経験があるからこそ、なれ合いと受け取られないよう、公平さには特に気をつけたいと考えています。
続けて聞かれること／「知り合いの業者が市の工事を受注したらどうしますか」。答えは同じです。他の業者と同じ対応をし、気になることがあれば上司に報告する。発注者と受注者は、上下ではなく対等な契約の関係です（問答集 Q48）。
F4市内に住んでいると、近所の方や知人から「うちの前の道を先に直してほしい」と頼まれることもあります。どうしますか。▶
意図 動画

「市民の目線」を強みとして話したので、その裏側を聞く質問です。地元に住む職員は、頼みごとをされやすい立場にあります。公平さを保てるかを見ています。

骨子
  • 話は丁寧に聴く。危険な状態なら、場所と状況を聞いて担当に伝える
  • ただし、知り合いだからといって順番は変えない。その場で「やります」と約束しない
  • 直す順番は、点検の結果や危険の度合いで決まることを説明する
  • 通常の窓口や手続きを案内し、頼まれたことは上司に報告する
お話は丁寧に伺います。危険な状態であれば、場所と状況を確認して担当に伝えます。ただ、知り合いだからといって順番を変えることはしません。その場で約束はせず、補修の順番は点検の結果や危険の度合いで決めていることを説明し、通常の窓口をご案内します。頼まれたことは上司にも報告します。市内に住んでいるからこそ、誰に対しても同じ対応をすることを意識したいと考えています。
F5「発注者や関係者から信頼をいただいている」とありますが、どんな場面でそう感じましたか。▶
意図 ES①

自分で書いた評価なので、根拠を聞かれます。大きな話は要りません。実際にあった小さな場面で十分です。

骨子
  • 実際にあった場面を一つ（次の現場も任された、役所の窓口で書類の直しが少ないと言われた、近隣の方から声をかけてもらった、協力業者から相談されるようになった、など）
  • なぜそう言ってもらえたと思うか（確認を怠らなかった、連絡を早くした、など自己PRの強みにつなげる）
  • 自分一人の力ではなく、職人や協力業者と一緒にやった結果だと添える
盛らない／実際に言われた言葉、実際にあった出来事だけを話してください。思い当たる場面がなければ、「大きな評価をいただいたわけではありませんが、同じ発注者から続けて仕事をいただいています」のように、事実の範囲で答えれば十分です。

骨子（相手ごとに一つずつ）

F8工程を遅らせられない現場で、安全と工期がぶつかったことはありますか。どう判断しましたか。▶
意図 ES②

「絶対に工程を遅らせられないという強いプレッシャー」と書いたので、その中で安全を後回しにしなかったかを確かめる質問です。

骨子
  • 最初に「安全を優先します」と言う
  • 実際の場面を一つ（雨、想定外の埋設物、資材の遅れ、など）
  • 作業を止める判断をしたこと。止めたあと、すぐに関係者へ連絡し、工程を組み直したこと
  • 自分一人で決めず、会社や発注者に報告して決めたこと
安全を優先します。私が担当した現場でも、引き渡しの日が決まっている中で、掘削してみると想定と違う状況が出てきたことがありました。その日は作業を止め、関係する方にすぐ連絡して状況を共有し、翌日以降の工程を組み直しました。早く知らせたことで、後の工程で調整していただくことができました。遅れそうなときほど、早く伝えることが大事だと考えています。
注意／上の例の出来事は仮のものです。自分の現場で実際にあったことに置き換えてください。「工期のために多少は無理をした」と受け取られる話は選ばないこと。
F9交通規制の時間内に作業が終わりそうにないとき、どうしますか。▶
意図 ES②

骨子

  • 終わらない見込みが出た時点で、その日の作業範囲を切り上げる。仮の復旧をして、時間内に道路を開ける
  • 残りは翌日以降に回し、関係者に連絡して工程を調整する
  • そうならないよう、1日の作業量に余裕を持たせて計画している

F10「現場全体で徹底した」とありますが、職人さんや協力業者に、どうやって守ってもらいましたか。▶
意図 ES②

F11施工マニュアルや安全基準を「毎回」確認するとのことですが、慣れた作業でも毎回ですか。時間がかかりませんか。▶

  • 同じ工事でも、現場ごとに埋設物・交通・近隣の条件が違う

F12市民の声を丁寧に受け止めたい、とのことですが、すべての要望には応えられません。どうしますか。▶

「はい」「いいえ」「事実」から始める
条件を確かめる質問は、人事の担当者が事実を知りたくて聞いています。前置きをせず、一言目で答え、理由を一文だけ足してください。迷うそぶりが出ると、「本当は気にしているのでは」と受け取られます。面接までに、事実を自分の中で決めておくことが準備です。

CH.6

逆質問と最後の一言

G1最後に、何か質問はありますか。▶
骨子
  • 2つ用意して、聞くのは1つ。25分の終わりで時間が押していることが多い
  • 入庁する前提の、前向きな質問にする

選び方

  • 部長級や市長など役職の高い方がいるときは「市の方向性」から、人事の方が中心のときは「入庁までの準備」「入庁後の仕事」から選ぶと自然

  • 入庁後は、先輩の方について現場を回りながら仕事を覚えていく形になるのでしょうか。

  • 市民の方から土木の担当に寄せられる声で、多いのはどのようなものでしょうか。
市の方向性（役職の高い方がいるとき）
  • 土木の分野で、これから特に力を入れていかれることを伺えますか。
  • 災害への備えとして、技術職の職員に日頃から求められていることは何でしょうか。
  • 限られた財源の中でインフラを維持していくうえで、技術職の職員に期待されている役割を伺えますか。
答えをいただいたあとの一言
  • ありがとうございます。入庁までに、〜から準備を始めます。
  • ありがとうございます。その点を意識して、仕事に取り組みます。
聞かないほうがよい質問／給与、手当、残業、休暇、配属の希望。採用人数や勤務時間など、募集要項や市のサイトを見れば分かること。「私の評価はどうでしたか」など合否に関わること。市への要望や苦情に聞こえること。面接の中で答えが出ていた場合は、「先ほどのお話でよく分かりました。入庁までに〜を勉強しておきます」と意欲を一言伝えて終えれば十分です。「特にありません」だけで終えないこと。

CH.7

    CH.9

    当日の動き

    市からの案内が最優先です
    集合時刻、集合場所、持ち物は、市から届いた案内（メールや受験システムの通知）のとおりにしてください。この資料は、その案内の中身を見ずに作っています。下は一般的な注意です。
    前出発から受付まで▶
    • 服装はスーツ。作業着や現場の服では行かない
    • 持ち物：案内で指定されたもの、筆記用具、エントリーシートの控え、腕時計、ハンカチ
    • 集合時刻の10〜15分前に庁舎に着く。早く着きすぎたら、外で控えを読み返す
    • 遅れそうなとき、体調が悪いときは、分かった時点で人事課に電話する（072-971-5196。市役所の電話受付は9時〜16時30分）
    • 庁舎に入ったら、スマートフォンの電源を切る
    • 住んでいるまちの市役所です。庁舎の中や行き帰りで会う人は、職員かもしれません。敷地に入ったところから面接が始まっていると考えてください
    中入室から退室まで▶
    • ノックして「どうぞ」を待つ →「失礼いたします」→ 椅子の横で、受験番号と氏名（指示があれば、そのとおりに）→「よろしくお願いいたします」→「おかけください」と言われてから座る
    • 背もたれに寄りかからない。手は膝の上
    • 目線は、質問した人を中心に。面接官が複数いるときは、ときどき全員を見る
    • 声は、現場で話すときより少しゆっくり。語尾まではっきり
    • 終わったら、座ったまま「ありがとうございました」→ 立って椅子の横で一礼 → 扉の前でもう一度「失礼いたします」
    うまく答えられなかった質問があっても、引きずらない／面接官は、一つの答えではなく、25分を通した人柄を見ています。次の質問を落ち着いて聞くことに切り替えてください。
