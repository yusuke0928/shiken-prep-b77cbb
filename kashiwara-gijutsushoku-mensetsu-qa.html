CH.1

志望動機と人物

01なぜ柏原市を志望したのですか。▶
意図

近隣市や大阪府ではなく、なぜここなのか。定着してくれる人かを見ています。技術職でも人物質問は必ず来ます。

骨子
  • 柏原との個人的な接点（住んでいる・通っていた・関わりがある）
  • 市の計画や地形など、具体的な事実を一つ挟む
  • 技術職として何を担いたいかで着地する
組み立て
柏原市は大和川と石川が合流し、東は生駒山地、西は玉手山に挟まれた土地で、河川・斜面・市街地の課題が一つの市に凝縮されています。第5次総合計画では2030年に「選ばれ、選び続けられるまち」を掲げていますが、それを支えるのは道路や水路といった土台だと考えています。生活の基盤をつくる側から、住み続けられるまちに関わりたいと思い志望しました。
02民間の建設会社ではなく、なぜ市役所の技術職なのですか。▶
意図

技術職の面接で最も突っ込まれる質問。「安定しているから」を疑われています。

骨子
  • 発注者側として、計画・設計から維持管理まで一つのまちに長く関われる
  • 採算が合わない地域も切り捨てず、公平に整備できるのは行政だけ
  • 市民生活と直接つながる仕事がしたい
注意／「技術力を磨きたいだけなら民間のほうが機会は多いのでは」と必ず返されます。技術の話ではなく、地域への責任に着地させてください。
03これまでに力を入れて取り組んだことを教えてください。▶
骨子
  • 課題 → 自分の工夫 → 周囲との関わり → 学び、の順で話す
  • 成果の大きさより、他人を巻き込んだ過程を厚く
  • 研究・実習・現場経験があれば技術系のエピソードを優先

役所は組織で動きます。個人の技術力より調整力が評価されます。1分程度に収め、深掘りの余地を残してください。

04あなたの長所と短所を教えてください。▶
骨子
  • 長所は必ず具体的なエピソードとセットで
  • 短所は実在するものを一つ。ただし改善のために今していることを添える
  • 「心配性」「慎重すぎる」は技術職ではむしろ長所に転びやすい
注意／「短所は特にありません」は最悪の回答。逆に「時間にルーズ」「人の話を聞かない」など、公務に致命的なものは避けます。
05希望しない部署に配属されたらどうしますか。▶
骨子
  • 技術職でも用地、施設管理、事務系の仕事に就く可能性を理解している
  • どの部署も市民生活に直結するので前向きに取り組む
  • 異動を通じて市全体を知ることが将来の判断力になる
06併願はしていますか。第一志望はどこですか。▶
骨子
  • 併願は正直に答える（隠しても不自然になる）
  • そのうえで「柏原市が第一志望です」と理由付きで言い切る
  • 理由は01の志望動機と矛盾させない
07ストレスを感じたとき、どう対処しますか。▶
意図

技術職は住民説明や災害対応で矢面に立ちます。長く働けるかを見ています。

骨子
  • 具体的な切り替え方法を一つ（運動・趣味など）
  • 一人で抱え込まず、相談できる相手がいる
  • 「ストレスを感じません」とは言わない
CH.2

柏原市を知る

08柏原市の魅力を一つ挙げてください。▶
素材
  • ぶどう栽培とワイン（カタシモワイナリー／斜面地の農業景観）
  • 亀の瀬の地すべり対策施設、高井田横穴群、智識寺跡などの歴史資源
  • 近鉄大阪線とJR大和路線の2路線があり、天王寺方面へのアクセスが良い
  • 山と川に囲まれた自然環境が市街地のすぐそばにある
注意／技術職なら、魅力を地形や基盤の話につなげると印象が強くなります。例：ぶどう畑は景観資源であると同時に、斜面地の土地利用と保全という技術的テーマでもある。
09柏原市の課題を一つ挙げ、どう関わりたいか教えてください。▶
骨子
  • 人口減少と高齢化、それに伴う税収減と施設の維持
  • 災害リスク（河川・土砂）と、インフラの老朽化
  • 空き家の増加、斜面地の住宅地と狭い道路
注意／課題は批判で終わらせず、必ず「だから自分はこう関わりたい」までセットにしてください。市の職員を前にした批判だけの回答は減点されます。
10柏原市の総合計画について知っていることはありますか。▶
押さえる点
  • 現行は第5次柏原市総合計画。2030年のまちの将来像を掲げている
  • キーワードは「選ばれる」「選び続けられる」まち
  • まち・ひと・しごと創生総合戦略では「子育て環境ナンバーワン」「働きやすい」「住んでみたい・住み続けたい」「暮らしやすい」の4つを基本目標としている
要確認／計画は改定されることがあります。面接前に市ホームページで現在の計画の版と将来像の文言を必ず確認してください。うろ覚えで言い切るのが一番危険です。
11柏原市のまちづくりで、あなたが改善したい点はどこですか。▶
素材
  • 斜面地の住宅地と狭あい道路（緊急車両の進入、擁壁の老朽化）
  • 柏原駅・河内国分駅周辺の歩行空間とバリアフリー
  • 空き家の増加と、跡地の活用
  • 農地・緑地の保全と、宅地との調和

一つに絞って、現地を見た印象を交えて話せると説得力が出ます。

12柏原市内で実際に見てきた場所はありますか。▶
意図

「地域密着」を口だけで言っていないかの確認。技術職では特に効きます。

準備
  • 亀の瀬地すべり資料室は見学可能。全国有数の地すべり対策事業を実地で語れる
  • 大和川と石川の合流点、堤防の高さや河川敷の使われ方
  • 山麓部の住宅地と、そこに至る道路の幅員・勾配
  • 駅前の歩道、段差、自転車の停め方
これが最大の差別化／実際に歩いて「ここがこうなっていた」と一言添えられる受験者は多くありません。見学の可否や日程は事前に確認を。
CH.3

技術職の専門

13柏原市の防災上の課題を、技術職の視点で説明してください。▶
意図

本命の質問。柏原の地形を理解しているかが一発で分かります。

骨子（3層で整理する）
  • 河川／大和川の外水氾濫と、市街地に降った雨が排けない内水氾濫
  • 斜面／山麓部に土砂災害警戒区域が分布し、住宅が近接している
  • 地すべり／亀の瀬は国が直轄で対策を続けている全国有数の地すべり地帯
柏原市は河川災害と土砂災害の両方を抱える地形です。ハード整備だけで完全に防ぐことはできないので、雨水排水などの施設整備と並行して、ハザードマップの周知や避難行動といったソフト面を組み合わせる必要があると考えます。
14老朽化したインフラにどう対応すべきだと思いますか。▶
キーワード
  • 事後保全から予防保全への転換
  • 道路法に基づき、橋梁やトンネルは5年に1回の近接目視点検が義務づけられている
  • 橋梁長寿命化修繕計画、公共施設等総合管理計画
  • 点検・診断・措置・記録のサイクルを回す
  • 人口減少で財源も職員も限られる前提を必ず入れる
すべてを同時に更新する財源はないので、点検結果に基づいて優先順位をつけ、壊れる前に手を入れる予防保全が基本になると考えます。同時に、利用実態が変わった施設は集約や規模の見直しも含めて検討する必要があると思います。
15柏原市の上下水道について知っていることはありますか。▶
最重要の事実
  • 柏原市の水道事業は令和7年4月に大阪広域水道企業団へ統合された
  • 同時に統合したのは岸和田市・八尾市・富田林市・高石市の計5団体
  • つまり現在は上水道は企業団、下水道は市の所管
  • 下水道の課題は管路の老朽化更新と浸水対策
ここを間違えると致命的／「柏原市の水道職員として働きたい」と言ってしまうと、制度を調べていないことが即座に露見します。受験する職種の担当範囲を募集要項で必ず確認してください。
16専門知識のない住民や事務職員に、どう説明しますか。▶
意図

技術職は住民説明会や用地交渉の前面に立ちます。「技術が分かる人」ではなく「技術を伝えられる人」を探しています。

骨子
  • 専門用語を使わず、図や写真、現地の写真で示す
  • 「なぜ必要か」「いつまでか」「生活にどう影響するか」を先に伝える
  • 相手が何を心配しているかを先に聞く
17工事に反対する住民がいたら、どう対応しますか。▶
手順で答える
  • まず反対の理由を具体的に聴く（騒音か、通行か、補償か、説明不足か）
  • 技術的に代替できる部分があるか検討する（工法・時間帯・動線）
  • 独断で判断・約束せず、上司や関係課と協議したうえで回答する
言葉選び／「説得します」は避けてください。「理由を伺ったうえで、できることとできないことを整理して説明します」が適切です。
18災害が発生したとき、技術職は何をすると思いますか。▶
骨子
  • 発災直後は道路・橋梁・水路・擁壁のパトロールと被害状況の把握
  • 通行止めなどの応急措置と、二次被害の防止
  • 応急復旧、その後の災害査定に向けた記録・写真の整理
  • 職員自身も被災者になりうるため、参集体制と分担を日頃から確認しておく

最後の一点まで言えると、組織で動く自覚があると評価されます。

19「道路に穴が空いている」と市民から通報が入りました。どう動きますか。▶
意図

土木職の日常業務そのものです。手順で答えられるかを見ています。

手順で答える
  • 場所と状況を聞き取り、まず現地を確認する
  • 市道か、府道・国道か、私道かを確認する（管理者が違えば所管課に引き継ぐ）
  • 危険なら現場でカラーコーンなどの応急措置を先に行う
  • 常温合材などで応急復旧し、必要に応じて本復旧を計画する
  • 対応内容を記録し、通報者にも結果を伝える
加点ポイント／道路の管理に瑕疵があって事故が起きれば、市が賠償責任を負うことがあります。「だから通報への初動が重要」まで言えると、責任の所在を理解していると評価されます。
20柏原市内の河川や水路は、誰が管理しているか分かりますか。▶
意図

管理区分を理解しているかは、土木職の基礎知識として問われやすい論点です。

押さえる考え方
  • 河川は等級と区間によって国・府・市と管理者が分かれる
  • 大和川は一級河川で、本川は国が管理している
  • 市が担うのは主に、法定外水路や雨水排水施設など身近な施設
  • だから浸水対策は、国・府・市の連携なしには成立しない
要確認／個々の河川・水路の管理者は区間ごとに異なります。断定せず「大和川は国管理、支川や水路は府・市」と大枠で答え、詳細は入庁後に確認したいと添えるのが安全です。
21発注者としての土木職は、具体的に何をする仕事だと思いますか。▶
意図

「現場で工事をする」と答えると、役割を理解していないと判断されます。

仕事の流れで答える
  • 計画・調査 → 設計（または委託の監督） → 積算 → 発注 → 工事監督 → 検査 → 維持管理
  • 用地交渉、関係機関との協議、住民説明も土木職の仕事
  • 予算要求や補助金の申請など、机上の業務も相当な割合を占める
設計や施工そのものは委託・請負で進みますが、何を、どの優先順位で、いくらでつくるかを決めるのは市の技術職です。現場に立つ時間だけでなく、積算や協議、説明までを含めて責任を持つ仕事だと理解しています。
22大学（高専）で学んだ土木の分野は何ですか。市でどう活かせますか。▶
つなげ方の例
  • 水理・河川／内水氾濫対策、雨水排水計画、流量計算
  • 土質・地盤／斜面地の安定、擁壁、亀の瀬のような地すべり地形の理解
  • 構造・材料／橋梁点検、コンクリート構造物の劣化診断、長寿命化
  • 計画・交通／通学路の安全対策、狭あい道路、駅周辺の歩行空間
注意／面接官の全員が土木出身とは限りません。専門用語を並べず、柏原市のどの課題に効くかまで翻訳して話してください。
23施工業者とは、どのような関係で仕事を進めるべきだと思いますか。▶
骨子
  • 発注者と受注者は対等な契約関係であり、上下ではない
  • 公平・公正な取扱いを徹底する（特定業者への便宜は絶対にしない）
  • 現場の安全と品質を確保するため、必要な確認と協議は遠慮なく行う

公務員倫理の観点が入っている質問です。接待や便宜供与を明確に否定できるようにしておいてください。

24建設業の人手不足について、行政としてどう向き合うべきだと思いますか。▶
意図

時事性のある質問。工事を担う地元業者がいなければ、市はインフラを維持できません。

骨子
  • 担い手が減れば、災害時の応急復旧を支える地元業者も減る
  • 時間外労働の上限規制を踏まえた適正な工期設定と、無理のない発注時期の平準化
  • ICT施工やドローン点検など、省力化技術の活用（i-Construction）
  • 設計変更や協議に発注者側が迅速に対応することも、現場の負担軽減になる
25入庁後に取りたい資格や、勉強したいことはありますか。▶
土木職で挙げやすい資格
  • 1級土木施工管理技士（監督業務の基礎になる）
  • 技術士補・技術士（建設部門）
  • 測量士補・測量士
  • コンクリート診断士（老朽化対策と直結する）

名前を挙げるだけでなく、「点検や監督の場面で必要になるから」と業務との結びつきを一言添えてください。資格より先に、現場を見て覚えたいという姿勢も忘れずに。

締めくくり

26最後に何か質問はありますか。（逆質問）▶
使える質問
  • 入庁までに勉強しておくべきことはありますか
  • 技術職の若手は、最初にどのような業務から担当することが多いですか

避けるべき質問／給与、残業、休暇、転勤の有無。調べれば分かることも聞かないこと。「特にありません」も熱意を疑われるので、必ず一つ用意してください。
