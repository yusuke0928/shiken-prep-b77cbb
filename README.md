## 内容を更新するとき

1. `_build/VERSION` の版を上げる（形式 `v<版>.<日付>`、例 `v2.20260903`）
2. 以下を実行して push

```sh
node _build/check.mjs      # 問題バンクを検査
node _build/build.mjs      # scoa-trainer.html を再生成し、index.html と sw.js の版表記も揃える
git add -A && git commit -m "..." && git push
```

pushの1〜2分後に公開サイトへ反映されます。利用者側には「新しい版があります」の案内が出て、押すと更新されます（学習記録は保持されます）。

版は **対策ハブの表紙** と **SCOAトレーナーのホーム画面の見出し下** に表示されます。本人に「今どの版か」を聞けば、更新が届いたか確認できます。Service Worker のキャッシュ名も `kashiwara-<版>` に自動で揃うので、`sw.js` を手で編集する必要はありません。

## 事務能力トレーナー（`scoa-jimu.html`）

今回の募集要項は第2次を「事務処理能力検査（SCOA総合適性検査）、約60分」としており、本人経由で事務処理能力検査であることを確認済み（2026-10-01）。NOMA総研の説明では、事務能力検査は照合・分類・言語・計算・読図・記憶の6領域で、速さと確実性を測る（約50分）。

- 問題は**その場で自動生成**する（問題バンクなし）。分野別（1分・2分・4分）と、6分野の通し練習
- 結果は回答数・正答・誤答・誤答率・1問あたりの秒数。誤答のときは時計を止めて正解を見せる
- 「各分野4分」「誤答は評価を下げる」「記憶は先に覚えて後で答える」は対策サイトや受験者の報告によるもので、公式には未公表。**形式は想定**であることをアプリ内にも明記している
- 版表記は `build.mjs` が差し込む。`sw.js` のプリキャッシュ対象

## SCOAトレーナーの使い方（基礎能力検査向け・今回は参考扱い）

### 収録内容

**420問／58小分野。** 本番（120問60分）に対して各尺度3倍以上の在庫があります。

| 尺度 | 収録数 | 本番の出題数 |
|---|---|---|
| 言語 | 65問 | 20問 |
| 数理 | 95問 | 25問 |
| 論理 | 95問 | 25問 |
| 常識 | 70問 | 20問 |
| 英語 | 95問 | 30問 |

### 出題モード

- **さくっと10問** — 苦手優先。トイレや信号待ち用。まずこれだけでよい
- **本番形式ミニテスト20問** — 本番の尺度比率で抽出
- **フル模試 120問60分** — 本番と同じ条件。月に1〜2回でよい
- **分野別に練習** — 苦手な小分野をピンポイントで
- **苦手だけ集中** — 正答率の低い分野を自動で選んで出題
- **間違いノート** — 間違えた問題だけ
- **★見返す問題** — 気になった問題にフラグを立てておける

### 覚えておくとよいこと

- **どこで閉じても続きから再開できます。** 1問答えるたびに保存しているので、電車を降りるときにそのまま閉じて構いません
- 制限時間は30秒ですが、**超過しても止まりません**。赤く「+4.2s 超過」と出るだけです
- 就寝前など気楽に解きたいときは、設定で**タイマーをオフ**にできます
- 「学習記録」で、小分野ごとの正答率が低い順に並びます。**赤くなっている分野が苦手**です
- 回答すると、正誤・解説に加えて**「関連知識」**（その問題の周辺論点。一般則・関連語・ひっかけ・派生論点）が出ます。間違えたときはここを読んでから次へ進むと、類題に対応できます
- ホーム以外のどの画面にも右上に**「ホーム」ボタン**があります。出題中に押すと中断の確認が出ますが、進捗は保存され「前回の続き」から再開できます

## 開発者向け（問題の追加・修正）

```
_build/
  SPEC-bank.md       問題作成の仕様
  SPEC-app.md        アプリの仕様
  SPEC-interview.md  面接資料の前提条件
  QA-findings.md     品質検査で摘出した指摘の記録
  check.mjs          問題バンクの検査スクリプト
  build.mjs          バンクを注入して scoa-trainer.html を生成。VERSION を各ファイルに差し込む
  VERSION            現在の版（例 v2.20260903）。更新時はここだけ書き換える
  render-test.mjs    生成した scoa-trainer.html をheadless Chromiumで開き、各画面と回答後の解説表示を検証（要 Playwright のChromium）
  app-shell.html     アプリのテンプレート
  bank/*.js          問題データ（8ファイル・420問）
```

問題を追加・修正したら：

```sh
node _build/check.mjs      # 全バンクを検査
node _build/build.mjs      # scoa-trainer.html を再生成
```

`check.mjs` は、問題数・ID重複・ID範囲・選択肢の妥当性・正解位置の偏り・解説の欠落・関連知識（`k`）の欠落と長さ・表構造・内容の重複を検査します。
